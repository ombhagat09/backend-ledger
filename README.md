# 🏦 Backend Ledger System

A Node.js + Express + MongoDB based banking ledger system implementing double-entry accounting and idempotent transactions.

## 🚀 Features

- JWT Authentication
- Account Management
- Double Entry Ledger System
- Real-time Balance Calculation (Aggregation)
- Idempotent Transactions
- Protected Routes
- MongoDB Indexing

## 🛠 Tech Stack

- Node.js
- Express.js
- MongoDB (Atlas)
- Mongoose
- JWT

git clone <repo-url>
